# 真实高清直播首帧标准

> 本文件定义角色首帧、定妆照和锚点图的验收标准。目标不是影楼写真，而是“真实高清手机直播首帧”。

## 核心原则

1. **真实质感**：拒绝过度美颜、胶感、盲目暴露和棚拍硬照。整体视觉像普通高清直播摄像头，保留真实皮肤纹理和生活/工作空间细节。
2. **多维差异**：角色不能只做单一美女审美；要覆盖不同职业、发型、发色、肤色、身材类型和空间类型，保持合理自然。
3. **公屏骚版**：当前只生产 `public_live` 公屏素材，采用骚版服装（蕾丝内衣/透丝袜/性感运动装等）。`private_live` 为未来功能，未上线。

## 固定要求

每一张首帧都必须满足：

1. 人物必须是成年女性，身体正对镜头，脸完全正对镜头，双眼直视镜头。
2. 镜头高度必须和人物眼睛平齐：平视，不俯拍、不仰拍、不侧拍。
3. 竖版 9:16，人物居中，画面从头到膝盖完整可见；不要拍太远，也不要裁掉头、腿或手。
4. 人物与背景都必须清晰：深景深、全画面清晰对焦。背景绝对不能虚化、不能糊、不能做电影景深或人像模式。
5. 画面整体明亮、均匀、曝光正常偏亮，但不能过曝；不要电影感、杂志硬照感、影楼感。
6. 场景真实、整洁、简约，背景元素清楚但不要堆太多。墙面、桌子、家具和主要物体尽量与镜头平行，画面端正不倾斜。
7. 姿势自然，像主播刚开播或正在和观众聊天；手部动作越简单越稳定，例如双手放膝盖、放桌面、轻微挥手、轻微前倾。

## 提示词书写顺序

生成首帧时按下面顺序写，模型最容易稳定理解：

1. 画面类型 + 人物基本信息。
2. 角色人设 + 面部表情。
3. 服装：颜色、单品、材质、版型。
4. 姿势、手部、视线、机位。
5. 场景和背景物件。
6. 光线、清晰度、构图、比例。

不要一开始堆背景细节，也不要把服装、姿势、灯光、场景全部塞进同一句。

## 替换槽

生成新角色首帧时，只改以下四类信息：

1. `【角色】`：健身教练、OL、画画主播、咖啡店主、游戏主播、教师、健康科普主播等。
2. `【服装】`：骚版生产层服装（蕾丝内衣 / 透丝袜 / 性感运动装等），不是日常/职业装。
3. `【场景】`：办公室、健身房、画室、咖啡店、民宿客厅、教室、诊室等。
4. `【姿势】`：坐姿、站姿、双手位置、轻微动作；优先选择稳定、简单、正面直视镜头的姿势。

## 人设转视觉语言

人设不要只写标签，要写成看得见的表情和身体语言。

| 人设 | 首帧表情与姿态 | 适合场景 |
| --- | --- | --- |
| 温柔体贴型 | 自然微笑，肩膀放松，双手轻放膝前 | 居家客厅、花店、护理科普 |
| 独立理性型 | 表情平静，眼神稳定，腰背挺直 | 健身房、办公室、科技直播间 |
| 活泼开朗型 | 明亮微笑，轻微挥手 | 游戏房、咖啡店、旅行场景 |
| 安静内敛型 | 微笑很轻，手势少，坐姿端正 | 书店、画室、音乐角 |
| 成熟稳重型 | 神情从容，双手自然交叠 | 书房、办公室、民宿客厅 |
| 外冷内热型 | 初见克制清冷，嘴角保留很轻的真诚笑意 | 独立书店、唱片店、夜间音乐角 |
| 古灵精怪型 | 眼神灵动，轻微歪头或小幅挥手 | 游戏房、甜品店、创意画室 |

## 稳定姿势库

坐姿优先，适合直播首帧和后续首尾帧视频：

1. 沙发正坐：坐在宽大沙发中央，双手放膝前，身体和脸正对镜头。
2. 沙发侧坐但脸正对镜头：双腿并拢偏向一侧，肩膀、脸、眼睛仍朝向镜头。
3. 扶手椅坐姿：坐在单人扶手椅中央，手放膝前或一手轻放扶手。
4. 地毯坐姿：双腿自然折叠收在身前，腰背挺直，双手并排放在膝前。
5. 宽大长凳坐姿：人物坐在长凳中央，两侧留出坐垫空间，便于画面稳定。

站姿用于需要完整展示服装或场景的角色：双脚自然站立，双手轻松交叠放在身前。

俯视躺姿只在明确需要上方机位时使用：必须写“摄像头位于人物正上方，镜头垂直向下”。

## 背景控制

每个场景只保留 3-5 个关键元素。背景越多，越容易生成杂物、文字和错误道具。

| 场景 | 推荐保留元素 |
| --- | --- |
| 居家客厅 | 暖白墙面、浅色沙发、干净地面 |
| 私人画室 | 画架、空白画布、原木画桌 |
| 独立书店 | 原木书架、少量无文字书籍、木地板 |
| 音乐休息角 | 单人扶手椅、原木吉他、落地灯 |
| 衣帽间 | 原木衣架、两件纯色外套、低矮收纳柜 |
| 健身房 | 浅灰墙面、少量器械、简洁长凳 |
| 海边 | 细沙、平静海面、平直海平线、淡蓝天空 |
| 山间民宿露台 | 原木墙面、栏杆、远处山景 |
| 屋顶露台 | 水泥墙面、低矮围墙、天空、远处楼宇轮廓 |

常用约束句：

```text
背景只保留【物件 A、物件 B、物件 C】，人物周围保持干净空旷。
```

```text
人物与背景同样清晰，前景、中景、远景全部清楚，不做背景虚化。
```

## 光线、质感与服装

室内直播优先：

```text
均匀明亮的室内正面光，整体曝光明亮但不过曝，真实普通高清直播摄像头质感。
```

室外直播优先：

```text
均匀明亮的日间自然光，整体曝光明亮但不过曝，真实普通高清手机直播摄像头质感。
```

服装要写具体：颜色 + 单品 + 材质/版型 + 整体气质。

```text
她穿深酒红色修身针织上衣与黑色高腰半身裙，服装贴合身形，整体成熟、利落、有自然女人味。
```

不要只写“性感”“氛围感”这种抽象词；要用剪裁、颜色、材质和角色场景来体现。

## 易翻车词

避免这些词或要求：

- `氛围感`、`电影感`、`人像摄影`、`浅景深`：容易把背景弄糊、弄暗。
- `侧身`、`回眸`、`低头`、`大幅度动作`：容易不直视镜头、脸歪或手崩。
- 背景描述太多：容易杂乱；每次保留 3-5 个关键物体就够。
- 同时要求 `全身` 和 `从头到膝盖`：二选一；当前统一用“头到膝盖”最稳定。

## 验收标准

只要以下六点都满足，首帧合格：

1. 人物直视镜头。
2. 镜头平视，与眼睛等高。
3. 背景和人物一样清晰。
4. 整体明亮，曝光正常偏亮。
5. 画面端正，墙面和家具不歪斜。
6. 角色和场景一眼能看懂。

## 首帧检查清单

- [ ] 是否明确是成年角色？

- [ ] 人物有没有裁头、裁脚或裁掉手？
- [ ] 人物和背景是否都清晰？

- [ ] 主线条是否端正平行，没有歪斜？
