# Public Live vs Private Live Mode System

生成提示词前，必须先确定直播间模式：`public_live` 或 `private_live`。
两个模式使用不同锚点、服装状态、灯光和互动尺度，但都遵守 `first_frame_standard.md` 的首帧验收标准。

## 模式对照表

| 维度 | public_live 公屏直播间 | private_live 私密直播间 |
| --- | --- | --- |
| 场景定位 | 1v多公开直播 | 1v1私密直播 |
| 服装状态 | 穿着日常或职业相关服装 | 单独私密服装状态；不复用公屏首帧 |
| 首帧要求 | 正面、平视、直视镜头、头到膝盖、深景深 | 同样正面、平视、直视镜头、头到膝盖、深景深 |
| 场景 | 职业/生活空间，如画室、办公室、健身房、教室、咖啡店 | 更私密的室内空间，灯光更柔和，背景仍真实清晰 |
| Idle | 公开直播微动作，职业/生活感 | 私密房间低幅度微动作 |
| Gift | AR 虚拟礼物，公开克制反应 | AR 虚拟礼物，更私密但仍自然的反应 |
| Action | 公屏可展示简单连续动作，不改变服装状态 | 私密简单连续动作 |
| 时长 | 8 秒 | 8 秒 |
| 首尾 | 首尾一致 | 首尾一致 |

## Public Live 首帧

public_live 的首帧必须像真实高清手机直播：

- 人物穿着符合职业或日常直播身份。
- 身体和脸正对镜头，双眼直视镜头。
- 镜头与眼睛等高，平视。
- 竖版 9:16，人物居中，从头到膝盖完整可见。
- 人物和背景同样清晰，深景深，不做背景虚化。
- 背景保留 3-5 个可识别的职业/生活元素。

## Private Live 首帧

private_live 必须使用单独首帧和 `private_anchor`：

- 不复用 public_live 的穿衣首帧。
- 房间、灯光、坐姿和互动氛围都与 public_live 区分。
- 仍然保持真实高清直播画面，不做影楼写真或电影感。
- 仍然要求正面、平视、直视镜头、头到膝盖、人物和背景同样清晰。
- 只用于 Idle / Gift / 简单单段 Action。
- Idle / Action 不写说话、声音、字幕或新增道具；Gift 可以一句短中文感谢口播。

## Gift 规则

两个模式的 Gift 都只使用直播平台 AR 虚拟礼物：

- 不使用男性手部。
- 不使用实物递入。
- 不做交接或归还动作。
- 特效在中段出现，尾帧前完全消散。
- 可以一句短中文感谢口播，但不能连续聊天，不能出现字幕或其他人声。

## Action 规则

两个模式的 Action 都是 8 秒简单连续动作。

禁止把 Action 写成分镜、按秒时间轴、多段流程、强剧情或后续拼接。

## 模式选择检查清单

- [ ] 是否明确选择 `public_live` 或 `private_live`？
- [ ] 当前模式是否有单独首帧和锚点？
- [ ] 首帧是否通过 `first_frame_standard.md` 验收？
- [ ] 是否只生成 Idle / Gift / Action？
- [ ] 是否固定 8 秒并首尾一致？
- [ ] Gift 是否为 AR 虚拟礼物并完全消散？
- [ ] Action 是否为简单单段动作？
- [ ] Idle / Action 是否没有说话、声音、分镜和新增道具？
- [ ] Gift 如果有口播，是否只有一句短中文，且没有字幕或其他人声？
