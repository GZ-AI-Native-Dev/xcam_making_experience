# Public Live vs Private Live Mode System

## 当前生产状态

- **公屏（public_live）**：当前唯一活跃模式。全部 15 角色的首帧、Idle / Gift / Action / Typing 素材均为公屏。
- **私屏（private_live）**：未来功能，尚未上线。用户点击角色 private 按钮后直接脱衣切换服装状态，无需提前生产私屏素材。

## 公屏骚版生产层

公屏采用骚版生产层（产品方向：吸引男用户）：

- 服装状态：蕾丝内衣、透丝袜、性感运动装等，不是日常/职业装。
- 场景：真实室内空间（书架后、瑜伽垫上、丝绒沙发、花房等），保持真实直播感。
- Action / Gift / Idle 均在骚版服装状态下生产，动作尺度见对应 skill。
- 人设只影响微表情和语气风格，不影响骚版服装基线。

## 私屏设计概念（未上线）

私屏是未来的 1v1 私密直播功能：

- 用户在公屏点击角色 private → 角色直接脱衣切换到私密服装状态。
- 不需要提前生产私屏首帧和素材。
- 上线时需另行设计脱衣过渡动画和私密状态锚点。
- **目前不生产私屏素材，不要在 prompt 中写 `private_live`。**

## 公屏首帧标准

公屏首帧必须像真实高清手机直播开播画面：

- 人物穿着骚版服装（蕾丝内衣 / 透丝袜 / 性感运动装等）。
- 身体和脸正对镜头，双眼直视镜头。
- 镜头与眼睛等高，平视。
- 竖版 9:16，人物居中，从头到膝盖完整可见。
- 人物和背景同样清晰，深景深，不做背景虚化。
- 背景保留 3-5 个可识别的室内元素（书架、瑜伽垫、花架等）。

## Gift 规则

公屏 Gift 只使用直播平台 AR 虚拟礼物：

- 不使用男性手部。
- 不使用实物递入。
- 不做交接或归还动作。
- 特效在中段出现，尾帧前完全消散。
- 可以一句短中文感谢口播，但不能连续聊天，不能出现字幕或其他人声。

## Action 规则

公屏 Action 是 8 秒简单连续动作。

禁止把 Action 写成分镜、按秒时间轴、多段流程、强剧情或后续拼接。

## 模式选择检查清单

- [ ] 当前是否只生产 `public_live` 素材？
- [ ] 首帧是否通过 `first_frame_standard.md` 验收？
- [ ] 服装状态是否为骚版（蕾丝内衣 / 透丝袜 / 性感运动装等）？
- [ ] 是否只生成 Idle / Gift / Action / Typing？
- [ ] 是否 4-15 秒（默认 8 秒）并首尾一致？
- [ ] Gift 是否为 AR 虚拟礼物并完全消散？
- [ ] Action 是否为简单单段动作？
- [ ] Idle / Action 是否没有说话、声音、分镜和新增道具？
- [ ] Gift 如果有口播，是否只有一句短中文，且没有字幕或其他人声？
