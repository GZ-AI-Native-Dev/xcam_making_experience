# 真实直播角色系统（最高优先级之一）

## 核心原则

角色的吸引力来自可相信的生活、职业和互动，而不是单一的外貌展示。每个角色先定义为一位**成年虚构人物**，再确定外观、场景、静默动作和直播内容；不要把角色写成只有身材或衣着的空壳。

每个角色卡都必须包含：

1. **身份**：职业或稳定生活状态；学生角色必须明确为成年人（例如研究生、成年艺校生）。
2. **直播地点**：与身份相符、可长期复用的真实空间。
3. **直播习惯**：镜头前常做的小事，必须是静默低幅度动作。
4. **职业痕迹**：只使用首帧或参考图中已经可见的服装、背景和物体。
5. **首帧设定**：按 `first_frame_standard.md` 写出真实高清直播首帧，保证正面、平视、深景深、头到膝盖。
6. **性格模板**：从 `personality_templates.md` 选择一种，并贯穿所有状态。

## 外观与场景多样性

- 年龄表达只使用明确成年角色；外观可涵盖不同发长、发色、肤色、身高和体型，但保持自然可信。
- 同一角色保留稳定的发型、常用妆感、体态和几件可识别的日常衣物，避免每段视频都像换了一个人。
- 场景允许有真实的“不完美”，但提示词只能命名首帧中已经存在且清晰可辨的物体。
- 不使用奢华样板间、空无一物的背景或过分光滑的皮肤质感，除非角色设定确实需要。
- 首帧背景只保留 3-5 个关键物体，确保角色和场景一眼能看懂；不要堆叠太多细碎物件。
- 首帧必须采用深景深和全画面清晰对焦，不写“氛围感”“电影感”“人像摄影”“浅景深”。

## 写入提示词的顺序

`成人身份 + 真实空间 + 参考图已有可见元素 + 正面平视首帧 + 静默微动作 + 性格变量 + 自然直播画面规则`。

先写角色正在做什么，再写她如何看镜头；不把“展示身材”当作默认动作。
