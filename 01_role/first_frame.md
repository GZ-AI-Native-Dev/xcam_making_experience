# 首帧生产 Skill

> 首帧 = 直播角色的定妆照，也是后续图生视频（I2V）和首尾帧视频（FL2V/FL2VA）的视觉锚点。
> 目标不是影楼写真，而是**真实高清手机直播开播画面**：人物直视镜头、机位平视、背景清楚、画面端正、姿势自然。
> 验收标准的完整细节（示例、背景控制、易翻车词）见 `01_role/first_frame_standard.md`。

## 1. 三种制作方式

| 方式 | 适用 | 做法 |
|---|---|---|
| **方式一：生图工作台 + 明星 Lora** | 有专门明星 LoRA 的角色 | 生图工作台选文生图明星 LoRA（按中文名/英文名/拼音缩写搜索）→ 粘贴首帧提示词 → 尺寸 9:16 → 多张生成 → 人工挑最适合直播的一张 |
| **方式二：角色专属画布** | 批量生产管理 | 「我的画布」按角色单独建画布 → 图片节点选文生图 LoRA + 提示词生成。**一个角色一个画布**，避免首帧、视频节点和提示词混在一起 |
| **方式三：Krea / edit 改图** | 没有专门 LoRA，或目标是网红/素人 | 准备 1080P 以上清晰照片 → Krea 图像编辑或 edit 类模型 → 保留人物识别度，同时重构服装、场景和姿势成直播间需要的样子 |

方式三边界：只做气质、光线、服装状态、背景整洁度和直播感的优化；不能把人物改成不像本人，不能做成写真/海报/电影构图。可识别真人只做非露骨角色图。

## 2. 首帧提示词模板

```text
真实高清手机直播画面，一位成年东亚女性【角色】，二十多岁，【发型】，
五官自然耐看，真实皮肤纹理，不过度磨皮。她拥有健康自然的身材比例，气质【人设关键词】。

她穿【颜色、版型、材质明确的服装】，整体【穿搭风格】。

她正面【坐在/站在】【具体位置】，身体与脸完全正对镜头，双眼直视镜头。
摄像头高度与她的眼睛完全平齐，平视视角。她【简单手部姿势】，表情【表情】，
像正在开启直播、和观众聊天。

背景是简约真实、明亮整洁的【场景】：【3-5 个关键物件】。
人物与背景同样清晰，前景、中景、远景全部清楚，不做背景虚化。

均匀明亮的室内光线，整体曝光明亮但不过曝，真实普通高清直播摄像头质感。
人物居中，竖版 9:16，从头到膝盖完整可见。
```

替换槽只改四类：`【角色】`、`【服装】`、`【场景】`、`【姿势】`。书写顺序和背景控制细节见 `01_role/first_frame_standard.md`。

## 3. 生产流程

1. 选方式（有 LoRA 走方式一/二，没有走方式三）。
2. 按模板填提示词；当前只生产公屏（public_live）首帧，采用骚版服装（蕾丝内衣 / 透丝袜 / 性感运动装等），见 `01_role/mode_system.md`。私屏为未来功能，暂不出素材。
3. 尺寸固定 **9:16**，多张生成（批量张数），人工挑选。
4. 过验收（§4）。不过不进视频生产。
5. 记录交付物：首帧图 + 首帧提示词 + 使用的明星 LoRA 或 edit 模型。

## 4. 验收标准

- 成年女性；身体、脸和眼睛都正对镜头。
- 镜头高度与眼睛平齐；不俯拍、不仰拍、不侧拍。
- 竖版 9:16；人物居中；头到膝盖完整可见，不裁头/腿/手。
- 人物和背景同样清晰；背景不能虚化、不能电影景深、不能人像模式。
- 场景真实、整洁、简约；墙面、桌面、家具尽量与镜头平行，画面端正。
- 整体明亮均匀，曝光正常偏亮不过曝，普通高清直播摄像头质感。

## 5. 易翻车词

- `氛围感`、`电影感`、`人像摄影`、`浅景深` → 背景变糊变暗。
- `侧身`、`回眸`、`低头`、`大幅度动作` → 不直视镜头、脸歪、手崩。
- 背景描述超过 5 个物件 → 杂物、文字、错误道具。
- `全身` 和 `从头到膝盖` 混写 → 二选一，统一用"头到膝盖"最稳。
